# Scope

This Working Group develops the FPSOT data types specification.

The specification covers how FPSOT systems store and exchange common kinds of data: text encoding and multilingual text, dates, times, durations, intervals and time zones, numbers, money, identifiers, booleans and code values, and geographic coordinates. For each type it sets one JSON form and one LinkML type, and it includes the machine-readable LinkML model of those types.

It does not cover how values are displayed or translated for people, the names of fields and code values, or the design of application programming interfaces.

Any changes of Scope are not retroactive.
